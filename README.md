# All-in-One Network Tracker

## Project Overview
All-in-One Network Tracker is a Python-based desktop application designed to perform network monitoring and troubleshooting tasks through a modern graphical user interface.

## Features
- Public IP Finder
- Private IP Finder
- MAC Address Finder
- Hostname Finder
- DNS Lookup
- Ping Test
- Traceroute
- Port Scanner
- Website Connectivity Checker
- Network Interface Details
- Export Results as Text Report
- Clear Results

## Technologies Used
- Python
- Tkinter (GUI)
- Socket Programming
- Subprocess
- Threading

## Requirements
- Python 3
- Windows operating system recommended
- Internet connection for online features

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open Command Prompt in the folder.
4. Run:

   python main.py

## Project Objective
To develop a simple graphical network diagnostic tool that helps users examine IP addresses, test connectivity, inspect network routes and perform basic network troubleshooting.

## Security Note
Only scan devices and networks for which you have permission.
